# Scenarios & Speaker Rotation

Rotate these 7 scenarios across the days, mapped to the month theme
(see `months-plan.md`). Vary the speakers so no two consecutive days feel the same.

> Domain note: the table below is the default IT set. For another domain,
> replace it with the scenario list from `<workspace>/profile.md`, keeping the
> rotation principle (no two consecutive days with the same scenario/speakers)
> and one scenario per day. See `references/learner-profile.md`.

| # | Scenario | Speakers (EN / AR) | Month focus |
|---|---|---|---|
| 1 | Daily Standup / Status Update | Manager / Tech — **المدير:** / **الفني:** | M1 status, M4 blockers + deadlines |
| 2 | Troubleshooting & Escalation | Tech / User — **الفني:** / **المستخدم:** | M2 cause→fix, M5 API/cloud faults |
| 3 | Vendor / Management Discussion | Tech / Manager — **الفني:** / **المدير:** | M4 budget/risk, M6 negotiation |
| 4 | Professional Email Writing | Writer / Recipient thread | M1 5 lines → M6 9–12 persuasive |
| 5 | Mentoring a Junior Engineer | Mentor / Junior — **المرشد:** / **المبتدئ:** | M1 Group Policy → M6 coaching |
| 6 | Teams Messages | Short thread with @mention | M1 simple → M4 threads/tagging |
| 7 | Meeting Discussion | Mixed (interrupt politely, summarize) | M1 taking turns → M6 leading |

Ground every scenario in the learner's world as defined in
`<workspace>/profile.md` (default IT example: 5,000 devices, AD, Intune
3,000-device patches, Zabbix 08:15 alerts, Veeam restores, FortiGate,
Entra ID). Never generic fillers ("John goes to the shop"). Keep one scenario per day.
