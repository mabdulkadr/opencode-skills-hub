## Folder vs. skill name

OpenCode keys skills off the `name` in `SKILL.md` frontmatter, not the folder name. One folder differs:

| Folder | `name` |
|--------|--------|
| `Business-English-IT-Pro-Skill` | `business-english-it-pro` |

Use the frontmatter name when invoking the skill or when writing `permissions` entries.

## Invoking skills

Skills are loaded by OpenCode through the `skill` tool using the frontmatter `name`. They can also be referenced by agents and commands, requested explicitly by the user, or selected automatically when a request matches the description. Descriptions drive automatic selection, so keep them precise when editing.

## Notes

- Descriptions here are condensed from each skill's `SKILL.md` frontmatter; the `SKILL.md` body is authoritative.
- Some skills bundle assets (`references/`, `scripts/`, `resources/`, `assets/`, `data/`, `themes/`). Keep them next to `SKILL.md` when copying; do not flatten or copy `SKILL.md` alone.
- Several skills carry upstream license files; see [LICENSES.md](LICENSES.md).
- Sources: [openskills.cc/skills](https://openskills.cc/skills), [web-dev-agent](https://github.com/Domenico-Tenace-Open-Labs/web-dev-agent), and the individual upstream authors named in each `SKILL.md`.
